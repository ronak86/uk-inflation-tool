Features

All weights, index values, and source series used in the calculations are published by the ONS. All the relevant formulae can be found in the very handy Consumer Prices Indices Technical Manual, 2019.

Built with ChatGPT Codex 5.5 Medium intelligence. After manually compiling a spreadsheet of weights, prices and sector definitions, the model was given the Technical Manual and figured out all the formulas, after which I kept iterating to add new features and correct mostly cosmetic errors.

Inflation Views

  • CPI, CPIH and RPI
  • Month-on-month and year-on-year views
  • Weights, price changes, and contribution estimates
  • Full basket drill-down from headline to item level

Custom Baskets

  • Services vs goods
  • Core vs non-core
  • BoE measure and ex-BoE views for CPI and CPIH
  • Reconstructed sub-index price changes

Workflow

  • Copy/paste neatly into Excel
  • Links back to ONS time series from weight and price codes
  • Right-click month headers to sort largest to smallest
  • Right-click Name to return to alphabetical/order view

Checks

  • Error checks against headline inflation
  • CPI, CPIH and RPI MoM and YoY error grids
  • Errors shown in basis points
  • Best used on desktop
The errors tab compares the calculated sum of the most detailed component contributions with the headline inflation rate derived from the published overall index. Small differences arise because the public weights and index values are rounded, so component-level calculations will not always add exactly to the official headline rate.
